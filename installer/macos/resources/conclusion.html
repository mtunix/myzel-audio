Removing plugins later

Run this installer again and tick a row under Remove, or in Terminal:

sudo "/Library/Application Support/Myzel Audio/uninstall.sh" removes everything; add plugin names (for example @FIRST_PLUGIN_ID@) to remove only those.

Presets and settings in ~/Library/Application Support/Myzel Audio are never touched.
